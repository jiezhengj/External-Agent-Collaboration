# Handoff templates by task boundary

Use only the smallest relevant template. All templates exclude secrets and the complete Codex transcript.

## Code or local file execution

- Objective and machine-readable expected outcomes.
- Allowed paths, explicit delete/binary exceptions, and exact validation commands.
- Relevant source files, tests, constraints, and prohibited operations.
- For high-risk completion: use one independent critique after execution; do not initiate a debate loop.

## Document, planning, or research analysis

- State the question, audience, supplied local sources, known facts and desired format.
- The collaborator may analyze or draft plaintext only.
- Codex obtains current sources itself and creates final `.docx`, spreadsheet, presentation, PDF, or image with native tools.

## Creative work

- State brand/audience/constraints and ask for alternatives with trade-offs.
- Treat output as candidates, not factual conclusions; record the chosen option only when the user or Codex selects it.

## Data work

- Identify non-sensitive local inputs, required calculations, output schema and verification query/test.
- Do not send production/customer exports. Final spreadsheet artifacts stay on the native Codex path.

## Personal advice

- Do not delegate routine advice. Delegate only when the user supplied long non-sensitive local material or explicitly requested an independent second opinion.

## Never delegate

- Timely facts, logged-in connector data, credentials, private keys, customer/production exports, final rich office artifacts, deployments, destructive infrastructure work, or a request whose content itself is sensitive.
