# 外部 Agent 协作技能架构图

本图说明当前已验收的产品分工和技术边界。适用于 macOS 与 Windows；两端各自使用 Git 忽略的本地 profile、trust 和运行态记录，绝不交换 CLI session 或凭据。

## 产品架构：谁处理什么任务

```mermaid
flowchart TB
    User["维护者请求"] --> Codex["Codex\n统一入口与协调者"]
    Codex --> Gate{"敏感性与任务分类\n可否离开 Codex？"}

    Gate -->|"敏感 / 原生能力 / 简单任务"| Native["Codex 原生处理\n或拒绝外发"]
    Gate -->|"已有精确 session"| Continuity["恢复所属 harness 的 session"]
    Gate -->|"普通项目协作 / 受控修改"| ClaudeRole["Claude Code\n项目协作者（默认）"]
    Gate -->|"新主题 + 只读 + 明确独立审查"| AgRole["Antigravity\n独立审查者"]

    ClaudeRole --> Pool["DeepSeek / MiMo\nClaude Code 内按 routing policy 选择\n缺省为公平轮换"]
    Pool --> ClaudeCLI["Claude Code CLI\n受控读取、修改与验证"]

    AgRole --> AgCLI["Antigravity CLI\nplan 模式只读 consult / critique"]
    AgCLI -.-> Blocked["自动执行未启用\n不得加入 DeepSeek/MiMo 池"]

    Continuity --> ClaudeCLI
    Continuity --> AgCLI
    ClaudeCLI --> Result["脱敏结构化结果\n状态、session、验证与风险"]
    AgCLI --> Result
    Native --> Result
```

关键规则：Claude Code 是唯一的自动项目 execute harness。Antigravity 只能处理无历史、无敏感、只读且明确要求第二方案、反方意见或风险审查的任务；它在 macOS 与 Windows 的隔离写入验证均未完成唯一目标，因此不升级为执行器。

## 技术架构：请求如何成为可审计结果

```mermaid
flowchart LR
    Request["请求 + 脱敏 handoff"] --> Sensitivity["sensitivity.py\n前置分类 + 最终 handoff 扫描"]
    Sensitivity --> Classifier["classify_task.py\nnative / direct / external"]
    Classifier --> Router["角色路由\nsession、用户指定、风险、平台与能力"]

    subgraph Claude["Claude Code harness"]
        ProviderRouter["provider_routing.py\nfair / fixed / weighted routing"] --> CAdapter["ClaudeCodeAdapter"]
        CAdapter --> CCLI["claude headless CLI\nJSON Schema + precise resume"]
    end

    subgraph Antigravity["Antigravity harness"]
        AAdapter["AntigravityAdapter"] --> ACLI["agy headless CLI\nplan + JSON/stream diagnostics"]
        AAdapter -.-> AExecute["自动执行未启用\n受控诊断入口"]
    end

    Router -->|"项目协作 / execute"| ProviderRouter
    Router -->|"独立只读审查"| AAdapter

    Profiles["Git 忽略本地 profile\n平台可分别配置"] --> CAdapter
    Profiles --> AAdapter
    Trust["非密钥 trust fingerprint\nprovider / harness / platform"] --> Router
    State[".ai-collaboration 运行态\nsession、health、capability、topic"] --> Router
    CCLI --> State
    ACLI --> State

    CCLI --> Guard["execute guard\nallowed paths / commands\ncheckpoint / outcome / rollback"]
    Guard --> Envelope["统一结果 envelope\n状态、external session、结构化输出\n脱敏诊断"]
    ACLI --> Envelope
    Envelope --> Records["Git 忽略 outputs / logs\n版本化 handoff / DEC / 文档"]
```

### 不可跨越的边界

|边界|规则|
|---|---|
|Harness 与 provider|Antigravity 是独立 harness，不是 DeepSeek/MiMo 的第三个 provider。|
|Session|session 绑定 harness、profile、provider、工作目录、平台与 workspace identity；禁止跨 harness/跨平台恢复。|
|凭据|token 只保存在 Git 忽略的 local profile；不得写入 handoff、输出、日志或版本库。|
|执行|Claude Code execute 必须通过允许路径、命令白名单、checkpoint、outcome 和 rollback；AGY execute 当前不可用。|
|跨平台|macOS 与 Windows 分别验证 launcher、路径、profile、trust、session 和 capability；共享的是规范，不是本机运行态。|
