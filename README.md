# External Agent Collaboration

[English README](README.en.md) · [中文 README](README.zh.md)

English: A project-local Codex Skill for coordinating persistent MiMo and DeepSeek collaborators through the local Claude Code CLI. It keeps task routing, sessions, file edits, validation, and review traceable without treating an external model response as proof that work is complete.

中文：一个项目级 Codex Skill，通过本地 Claude Code CLI 协调持续的 MiMo 和 DeepSeek 协作者。它将任务路由、会话、文件修改、验证和审查记录在本地，不把外部模型的一句“已完成”当作完成证据。
